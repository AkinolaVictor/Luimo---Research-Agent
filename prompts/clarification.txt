**INTERACTIVE BEHAVIOR:**

**Radio Button Selection:**
- Clicking radio button or label should select that option
- Only one option per clarification card can be selected
- Selection should trigger immediate visual update
- Clicking same option again should keep it selected (no toggle)
- Selection updates state in real-time

**Continue Button Interaction:**
- Initially enabled if form has no required fields
- Can be enabled/disabled based on validation
- On click:
  - Validate all required clarifications have selections
  - If invalid: Show error message or highlight unfilled cards
  - If valid:
    - Show loading state (optional: "Processing..." text, spinner)
    - Disable button during submission
    - Submit form data to parent component or API
    - Handle success: Show confirmation or navigate to next step
    - Handle error: Display error message, keep form editable
    - Clear loading state

**Form Validation:**
- All clarification cards are required by default
- Cannot submit with empty selections
- Show validation errors clearly (highlight cards, error message below)
- Validation runs on button click (not on every change)

**Keyboard Navigation:**
- Tab key cycles through all interactive elements (radio buttons, button)
- Shift+Tab goes backward
- Arrow keys change radio selection (up/down arrows cycle through options)
- Enter key selects focused radio option
- Space bar selects focused radio option
- Enter on Continue button submits form

**Error Handling:**
- If form submission fails: Display error message
- Error message appears below clarifications or as toast notification
- User can correct and resubmit
- Clear error on new selection
